### Prompt 3:
I am building FlightHub, a flight booking system using FastAPI,
SQLAlchemy 2.x and Pydantic v2.

The following files already exist — do not recreate them:
- backend/models.py      (Flight, Booking SQLAlchemy models)
- backend/database.py    (engine, SessionLocal, get_db)
- backend/schemas.py     (FlightBase, FlightCreate, FlightResponse,
                          BookingCreate, BookingResponse, CancelResponse)
- backend/routers/flights.py (flight listing, search, creation)

Create the file backend/routers/bookings.py

--- ENDPOINTS TO IMPLEMENT ---

1. POST /bookings
   - Request body: BookingCreate
   - Business logic (in this exact order):
     a. Check flight exists → if not, 404 "Flight not found."
     b. Check flight.seats_available > 0 → if not, 409
        "No seats available on this flight."
     c. Check seat_number not already taken on same flight with
        status="confirmed" → if taken, 409
        "Seat {seat_number} is already taken on this flight."
     d. Generate booking_reference using this exact function:
        import uuid
        def generate_reference() -> str:
            return "FH-" + uuid.uuid4().hex[:6].upper()
     e. Decrement flight.seats_available by 1
     f. Create and save the Booking object
     g. Commit and refresh both flight and booking
   - Response 201: BookingResponse
   - ALL checks must happen inside a single db transaction
   - Use db.begin() or handle commit/rollback explicitly

2. GET /bookings
   - Query parameters: name (str, optional), ref (str, optional)
   - If NEITHER name nor ref provided → 400
     "Provide at least one search parameter: name or ref."
   - Search by name: case-insensitive partial match on passenger_name
   - Search by ref: exact match on booking_reference
   - If both provided, ref takes priority
   - If no bookings found → 404 "No bookings found."
   - Response 200: list[BookingResponse]

3. DELETE /bookings/{reference}
   - Path parameter: reference (booking_reference string)
   - Business logic (in this exact order):
     a. Find booking by booking_reference → if not found, 404
        "Booking {reference} not found."
     b. Check booking.status != "cancelled" → if already cancelled,
        400 "Booking {reference} is already cancelled."
     c. Set booking.status = "cancelled"
     d. Increment flight.seats_available by 1
     e. Commit and refresh both
   - Response 200: CancelResponse with message:
     "Booking {reference} has been successfully cancelled."

--- CONSTRAINTS ---
- Use APIRouter with prefix="/bookings" and tag="Bookings"
- Use FastAPI Depends(get_db) for database sessions
- All DB queries must use SQLAlchemy 2.x style:
  db.execute(select(...).where(...)) NOT db.query()
- Import only from: fastapi, sqlalchemy, sqlalchemy.orm,
  backend.models, backend.schemas, backend.database, uuid, datetime
- The overbooking check (seats_available > 0) and seat decrement
  MUST happen atomically — do not check in one query and update
  in another without holding the transaction
- status field on Booking must be stored as lowercase string:
  "confirmed" or "cancelled"
- Do not put try/except around the entire function — only wrap
  the commit step
- Do not create any other file

#### Mistakes & Corrections:
- **Mistake 1**: Initially missed atomic transaction handling for overbooking check
  - **Correction**: Implemented using `db.begin()` to ensure seats check and decrement happen atomically
- **Mistake 2**: Did not validate seat availability before booking
  - **Correction**: Added explicit check for `seats_available > 0` before proceeding
- **Mistake 3**: Forgot to handle duplicate seat booking on same flight
  - **Correction**: Added query to check if seat is already taken with status="confirmed"
